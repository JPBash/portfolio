Application To-Do List

Une application web interactive conçue pour gérer des tâches quotidiennes de manière simple et intuitive. Ce projet met en valeur la manipulation dynamique du DOM et l'utilisation de l'état local dans le navigateur.

Fonctionnalités clés

  • Ajout et suppression rapide de tâches.
  • Marquage des tâches comme complétées avec animations.
  • Filtrage des tâches (Toutes, En cours, Terminées).
  • Persistance des données locales avec `localStorage`.

Technologies utilisées

HTML5 CSS3 JavaScript DOM Web Storage API
